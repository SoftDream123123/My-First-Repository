技术栈一共八项，我按四类说。前三项是底座：后端用 Python 三点一一以上，本机是在三点一三上验证的；Web 框架用 FastAPI，它只做纯 JSON 接口，不渲染页面；数据库用 MySQL 八点零以上，因为要用到 JSON 列和枚举类型，整个系统只有这一个库、十六张表，也没有引入迁移框架——表结构由建表脚本和模型两处对齐。第四项是前端：原生 HTML、CSS 和 JavaScript，用 Vite 构建，没有 UI 框架、没有图表库、也没有状态管理库。往下四项是结构。架构上前后端分离，开发期经 Vite 代理，演示期由后端托管前端产物，因为同源部署，所以整个项目没有一行跨域配置。分层上是严格的三层单向依赖，这条由测试直接断言。能力层做了抽象接口：AI 可以在 Mock 和真实实现之间切换，短信通道用了同一套写法、目前只有 Mock 实现，两者都做到没有外部账号也能完整演示、完整跑通测试。部署是单机同源，必须单进程运行，因为有两个关键状态在进程内。
