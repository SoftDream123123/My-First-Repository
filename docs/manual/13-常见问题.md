# 13 常见问题

这一章你会学会做什么：碰到提示不知所措时，对照下面的表找到「这句话是什么意思、我该做什么」。

> 这一章是给使用者看的排障问答。想了解功能规则与设计边界，看 [产品说明书](../production/产品说明书.md)。
> 表里凡是「系统起不来」这一类问题，都请转到仓库根目录的 [如何打开项目.md](../../如何打开项目.md) —— 那里把每种启动失败的原因和对应做法都列全了。

| 现象 | 怎么办 |
|---|---|
| 登录时提示「用户名或密码错误」 | 先确认用户名没有多打空格（比如末尾带了一个空格），再确认大小写和输入法。系统刻意不告诉你「是账号不存在还是密码错了」，所以这句话两种情形都会出现。确实忘了密码，请管理员在「用户管理」里重新给你开一个账号。 |
| 登录时提示「账号已禁用，请联系管理员」 | 你的账号被管理员停用了。找管理员在「用户管理」里把状态改回「已启用」，就能重新登录。 |
| 激活面试时提示「邀请码无效或已失效」 | 这一句话盖了四种情况：码打错了、已经被招聘方撤销了、过了 7 天有效期、已经被人用过了。逐项排除：先把码重新复制一遍（注意别带上前后空格），再问招聘方这张码是不是还在「待接受」。不管哪种原因，**都只能请招聘方重新生成一张**。 |
| 我本来就有账号，激活时也填了原来的用户名和密码，却提示「用户名或密码错误」 | 账号已存在时，密码是用来**核对身份**的，不是换一个新密码。请填你那个账号原来的密码。真忘了，就用另一个用户名激活，或者先请管理员处理。 |
| 激活时提示「用户名已被占用」 | 你填的这个用户名已经被招聘方（HR 或管理员）的账号用了。换一个名字再试。 |
| 激活时提示「你已接受过该面试的邀请」 | 这个账号已经绑过这一场面试了。直接去「我的面试」里进这一场就行，不用再激活一次。 |
| 交卷之后想改某一道题的作答，改不动了 | 这是有意这样定的：交卷是「交出去」的动作，交完之后作答就锁定了，**没有办法重新打开** —— 招聘方再发一次邀请也解不开。确实需要改，请联系招聘方，由他们在自己那边帮你修订。 |
| 想看自己的分数、逐题评价或者雷达图，却怎么也找不到 | 这些内容**不在**候选人能看到的范围里，页面上找不到是正常的。你能看到的是「综合结论」「优点」「待改进」；分数与雷达图属于招聘方那边的完整报告。如果连这几块都没有，看下面那条「反馈还没出来」。 |
| 打开反馈页，只看到「反馈还没出来」 | 说明招聘方还没把这场面试评估完。这不是出错 —— 评估完成后才能生成反馈。过一阵再来，或者在「我的面试」里看到那一行的按钮从「查看作答」变成「查看反馈」时，就是好了。 |
| 面试详情里的「按简历补题」是灰的，点不动 | 鼠标停上去看它给的原因。常见两种：一是写着「该面试尚未关联简历」—— 请候选人在他自己的「我的简历」里把简历「用于面试」关联到这一场；二是写着「当前状态不可补题」—— 只有「进行中」的面试才能补题。 |
| 刷题提交了，却没有马上判分，显示「未判分」 | 「未判分」不是「答错」。两种来由：这道题还没有参考答案，或者 AI 那一刻不可用。用这道题下面的「重判」按钮再试一次；它不计入正确率，也不会进错题本。 |
| 刷题页的「开始练习」是灰的 | 看筛选栏右边那句话。写着「没有符合条件的题目，换一组筛选条件」时，把条件放宽（比如把「不限难度」改回不限、或者减少筛选项）就能点了。 |
| 评估一直停在「评估中」，不动了 | 先重新加载这一页 —— 评估的任务通常还在后台跑，重新加载会接上它的进度。如果之前重启过系统，重新加载还会把上一次残留的「评估中」自动恢复到该有的那一步：本来没出过报告的，会重新出现「开始评估」，再点一次即可；本来已经有一份旧报告的，会回到那份报告上。另外注意：跑服务的那个窗口不要关，启动脚本里的参数也不要改（原因见 [如何打开项目.md](../../如何打开项目.md)）。 |
| 评估时看到「评估流已断开。评估任务可能仍在后台继续，重新加载即可接上进度。」 | 这不是评估失败，只是这一段进度没接上。照它说的重新加载页面，就能接上同一条任务。 |
| 导出的 Word 打不开 | 先确认下载完整了（文件大小不是 0）。如果下载那一步就报错了，提示里会跟着一句「（可改用「导出 PDF」）」—— 换成「导出 PDF」这条路即可。 |
| 打印出来的 PDF 没有样式 / 排版乱了 | 必须用页面上的「导出 PDF」按钮（它走浏览器打印），并且确认浏览器的打印设置里没有勾「简化页面」之类的东西。另外，导出的 Word 里本来就不含雷达图，想要带图的版本请用 PDF。 |
| 页面显示「网络连接失败」 | 说明服务没在跑，或者中途被关掉了。逐条排查的办法见 [如何打开项目.md](../../如何打开项目.md) 第三节「报错了怎么办」。 |
| 换了一台电脑，或者换了一个浏览器，登录状态就没了 | 登录状态是记在**你用的那个浏览器**里的，换设备或换浏览器相当于从没登录过，重新登录一次即可。另外登录状态本身也有有效期，放了很久之后会要求重新登录，这是正常的。 |
| 删除岗位 / 删除题目 / 删除简历时被拒绝了 | 这三样都带「被引用就不能删」的保护：岗位下还有题目或面试、题目已被某场面试引用、简历已被面试或练习关联，都会拒绝并告诉你原因。先把那些引用解开再删 —— 这是在保护已有记录能被解释清楚。 |
| 候选人端的「我的面试」里一条都没有 | 三种可能：还没拿邀请码激活；邀请码已被撤销或过期；招聘方还没把面试发给你。先拿邀请码走一次「凭邀请码激活」；已经激活过还是空的，请联系招聘方确认那场面试和邀请码的状态。 |
| 岗位页里「创建题目」按钮是灰的 | 题目必须挂在岗位上。鼠标停上去会写着「请先创建岗位」。先去「岗位」页建一个岗位，再回来建题。 |
