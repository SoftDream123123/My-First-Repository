# 操作手册

这份手册是给**真正用它的人**看的 —— HR、面试官和候选人。它不讲系统内部怎么搭，只讲一件事：**这个按钮点下去会发生什么，你该照着点哪里。**

一共 13 章，按「谁在用、要干什么」分：前七章是 HR 和面试官这一侧（登录、用户、岗位、题库、面试、评估、面试前准备），后五章是候选人这一侧（账号与激活、我的面试、我的简历、刷题练习、错题本与练习统计），最后一章是排障问答。每一节讲一个操作，配一张流程图。

## 怎么用这份手册

1. 不知道从哪下手 —— 先看下面的「模块目录」，找到你要做的那件事，点进对应的章。
2. 想照做 —— 每节里的「怎么做」是一步一步的，按钮名和输入框名都照着界面上的原话写，照着点就行。
3. 点完不知道对不对 —— 每节末尾的「你会看到」写清了成功和失败各会弹出什么话。
4. 卡住了 —— 去 [13 常见问题](13-常见问题.md)，对着「现象」找「怎么办」。

> 还没把系统跑起来？那不是这份手册的事 —— 看仓库根目录的 [如何打开项目.md](../../如何打开项目.md)，照它双击一个文件就行。

## 怎么看流程图

每一节都有一张**流程图**，用 Mermaid 画在正文里：

- **在网页上看** —— 把仓库放到 GitHub 或任意支持 Mermaid 的地方，图会直接渲染出来。
- **在 VS Code 里看** —— 打开 Markdown 预览即可（需要装一个支持 Mermaid 的预览扩展）。
- **不想装任何东西** —— 每张图下面都跟着一行链接指向 `diagrams/` 下的 `.drawio` 源文件，那是同一张图的可编辑版本。

`.drawio` 文件怎么打开：

- 装了 draw.io 桌面版，直接双击它；
- **没装也不要紧** —— 打开 <https://app.diagrams.net>，把文件拖进去，就能看、能改、能另存。

每张图的含义：

| 形状 | 意思 |
|---|---|
| 圆角方块（绿） | 起点或成功的终点 |
| 方块（蓝） | 你要做的一步 |
| 菱形（黄） | 一个岔路口，要你判断 |
| 方块（红） | 出错时会看到什么提示 |
| 虚线方块（灰） | 补充说明，不是一步操作 |

> 注意：上面这张图例说的是 `diagrams/` 下 `.drawio` 源文件里的配色。正文里的 Mermaid 只用了三种颜色 —— 绿（起点或成功的终点）、红（出错提示）、灰（补充说明）；步骤方块和判断菱形在 Mermaid 里是默认配色。

菱形分出来的每条线上都写着**你在页面上真正会看到的那句话**（比如「没填全」「已被占用」），照着它就能对上自己遇到的到底是哪条路。
